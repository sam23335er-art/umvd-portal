# УМВД | Служебный портал — Кемерово RP

Ролевой проект. Не является ресурсом МВД России; все звания, приказы и документы — игровые.

Портал работает в двух режимах — код один и тот же:

| | На Vercel (общий) | Файл с диска (автономный) |
|---|---|---|
| Где данные | общая база Postgres | только этот браузер |
| Кто видит изменения | все игроки | только этот браузер |
| Проверка прав | на сервере, обойти нельзя | в браузере |

## Публикация на Vercel — без командной строки

**1. Загрузите проект на GitHub**
github.com → New repository (например, `umvd-portal`) → Create → «uploading an existing file» → перетащите **всё содержимое** этой папки (кроме `node_modules`, если она есть) → Commit changes.

**2. Импортируйте в Vercel**
vercel.com → Add New → Project → выберите репозиторий → Deploy. Настройки менять не нужно — всё указано в `vercel.json`.

**3. Подключите базу данных (один раз)**
В проекте Vercel: вкладка **Storage** → **Create Database** → **Neon** (Serverless Postgres, бесплатный план) → Create → **Connect** к проекту.
Затем вкладка **Deployments** → у последнего деплоя «⋯» → **Redeploy**.

**4. Сразу войдите как владелец и смените пароль**
`https://ваш-проект.vercel.app/#/admin/login` — логин `SAMER`, пароль `1234samer1234`. Портал сам попросит сменить пароль.
Совет: свой начальный пароль можно задать заранее — Settings → Environment Variables → `OWNER_PASSWORD`, до первого открытия сайта с подключённой базой.

**Перенос данных из автономной версии:** в старой версии «Настройки портала» → «Данные портала» → «Скачать копию»; на сайте Vercel — «Восстановить из копии», затем «Удалить демо-данные».

## Автономный режим

Откройте `Открыть-портал.html` двойным щелчком. Данные хранятся в этом браузере — делайте резервные копии.

## Для разработчика

```bash
npm i
npm run dev          # интерфейс (автономный режим) на http://localhost:5173
npm run build        # dist/index.html — один файл
npm run build:api    # пересобрать серверную функцию api/index.js после изменений в src/local или server
npm run check        # проверка типов
npm test             # проверка прав и тем
DATABASE_URL=postgres://... npm run build && node server/dev.mjs   # серверный режим локально
```

```
src/local/      логика портала: права, операции, журнал (работает и в браузере, и на сервере)
server/         серверная часть: функция Vercel и хранилище Postgres
api/index.js    собранная функция Vercel (не редактировать вручную)
src/pages/      страницы: публичные, кабинет, портал, админ-панель
src/styles/     темы оформления
```
